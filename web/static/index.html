agent-telephone 测试页面

这是 T13 的后端占位页：web/server.py 的接口与 WebSocket 协议已可用， 完整页面（麦克风采集、播放、槽位/时延面板、历史与批跑）由 T14 实现 （web/static/index.html + app.js + pcm-worklet.js + style.css）。

当前可用的接口：

  • GET /api/scenarios
  • GET /api/calls、GET /api/calls/{id}、GET /api/calls/{id}/audio/{caller|ai}
  • GET /api/config、POST /api/replay
  • WS /ws/call（start / config / takeover / hangup + 16kHz PCM 帧）
